# ANGFUNK — интерактивный прототип

Экран «Сегодня» из [макета Figma](https://www.figma.com/design/4SQ7D7kkYPcxL3xzL7UYXq/Untitled?node-id=1-2287).

Открыть: https://EldarGaliamov.github.io/angfunk-prototype/

## Что можно протестировать

- Выбирать дни 14–20 октября и прокручивать неделю.
- Открывать ближайшее занятие или занятие из списка.
- Нажимать счётчики «Будут», «Не будут», «Без ответа» для фильтра учеников.
- Менять ответ ученика: счётчики обновляются, отметки сохраняются в localStorage.
- Переключать «Сегодня» и календарь в нижнем меню.
- Закрывать занятие крестиком, Escape, нажатием на фон или свайпом вниз за ручку.
- Проверять плавные переходы выбранной даты, нижней навигации и панели занятия.

Данные демонстрационные. Неделя и месяц воспроизводят календарь макета, а не текущую дату. Начальный экран соответствует 15 октября. В приложении нет сервера, авторизации и реальных учеников. Очистка данных сайта сбрасывает отметки.

## Запуск локально

Нужен Node.js 22 или новее. Без установки зависимостей:

```sh
node tools/serve.mjs
```

Затем открыть http://127.0.0.1:4173. Для публикации на GitHub Pages: ветка `codex/angfunk-prototype`, корень `/`.

## Реализация

HTML, CSS, JavaScript без сборки. Ширина макета — 375 px; на телефоне экран занимает доступную область. Системные элементы iPhone и рамка устройства убраны по запросу. Исходные иконки экспортированы из Figma. Medeo Sans хранится локально и распространяется по SIL OFL (см. `assets/OFL.txt`).

Анимации используют transform/opacity, прерываемые переходы и кривые из навыков Emil Kowalski/Jakub Krehel. Учитываются `prefers-reduced-motion`, управление клавиатурой и системный focus trap нативного `<dialog>`.
